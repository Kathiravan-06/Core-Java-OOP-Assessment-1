# Core Java OOP Assessment – 1

## About This Repository

This repository contains Java solutions for **Assessment 1 – Core Java Checkpoint (OOPS Design)**.

The assessment consists of 10 programming problems designed to practice and demonstrate Object-Oriented Programming (OOP) concepts using Java.

## Topics Covered

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Abstraction
- Abstract Classes
- Interfaces
- Method Overloading
- Method Overriding
- Runtime Polymorphism

## Questions and Solutions

| Question | Problem Name | Main Concepts |
|---|---|---|
| 01 | Employee Salary Processing | Abstraction, Inheritance, Polymorphism |
| 02 | Banking Account Management | Inheritance, Method Overriding |
| 03 | Online Payment Processing | Interfaces, Polymorphism |
| 04 | Vehicle Rental System | Inheritance, `super()`, Method Overriding |
| 05 | Employee Performance Bonus | Method Overloading, Method Overriding |
| 06 | Food Delivery Order | Inheritance, Method Overriding |
| 07 | Employee Access and Permission System | Interfaces, Polymorphism |
| 08 | Online Course Fee Calculation | Abstraction, Abstract Classes |
| 09 | Hospital Billing System | Abstraction, Method Overriding |
| 10 | E-Commerce Product Pricing | Inheritance, Polymorphism |

## Technologies Used

- **Programming Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)
- **IDE:** Any Java-supported IDE or editor
